# adsventure-web

Hospedagem estática de material da AdsVenture no GitHub Pages.

Cada peça mora em `d/<código>/index.html`. O código é sorteado e não é publicado
em lugar nenhum: quem tem o link entra, quem não tem não descobre por navegação.

`robots.txt` bloqueia buscador em todo o repositório, e cada página traz
`<meta name="robots" content="noindex, nofollow">`. Isso mantém o material fora do
Google, mas **não é senha**: repositório público é legível por quem chegar até ele.
Material que não pode ser lido por terceiro não entra aqui.
